## ✨ Fitur Undangan Digital
1. **Interactive Envelope Opening:** Gerbang Candi Bentar terbuka perlahan saat tombol *"Buka Undangan"* diklik.
2. **Background Audio Autoplay:** Memutar lagu tradisional Minang *"Baralek Gadang"* dengan pemutar piringan melayang.
3. **Nama Tamu Dinamis:** Mendukung URL parameter, contoh:  
   `https://reyonl.github.io/wedding-diah-made/?to=Nama+Tamu+Terhormat`
4. **Live Countdown Timer:** Menghitung mundur menuju Sabtu, 28 November 2026.
5. **Google Calendar Integration:** 1-klik untuk menyimpan agenda acara ke Google Calendar.
6. **Bento Grid & Full-screen Lightbox Gallery:** Dokumentasi foto pranikah beresolusi tinggi dengan navigasi keyboard dan touch.
7. **Amplop Digital:** Rekening BCA dan Mandiri dengan fitur salin nomor rekening instan.
8. **RSVP & Buku Tamu:** Form konfirmasi kehadiran dan doa restu (tersimpan di *localStorage*) serta tombol konfirmasi via WhatsApp.
9. **Desain Responsif:** Optimal di semua perangkat (smartphone, tablet, desktop).

## 💻 Menjalankan Secara Lokal
```bash
# Clone repository
git clone git@github.com:Reyonl/wedding-diah-made.git

# Masuk ke direktori
cd wedding-diah-made

# Jalankan local HTTP server
python -m http.server 8000
```
Buka browser pada: `http://localhost:8000/?to=Nama+Tamu`
